# 代码大陆 · 游戏化 Python 学习网站

> Code Continent — 一个用「闯关打怪」的方式学 Python 的单文件网页应用。
> 全部内容打包在一个 HTML 里，双击即可打开，不需要安装任何东西。

## 这是什么

给编程零基础的同学做的一套 Python 入门练习系统。把知识点拆成 **66 个关卡、5 个章节**，
每关都有「生活类比 → 核心概念 → 示例 → 本关任务 → 三道阶梯练习」的固定结构，
浏览器里直接写代码、直接运行、当场判对错。

## 特性

- **纯前端单文件**：一个 `index.html` 内含全部课程数据、样式与逻辑，离线也能打开
- **浏览器里跑真 Python**：用 [Pyodide](https://pyodide.org/) 把 CPython 编译到 WebAssembly，判题跑的是真正的 Python 解释器
- **游戏化**：XP 等级、连击、星级、徽章、头像框、隐藏宝箱，关卡地图沿路线逐个点亮
- **进度码跨设备搬运**：把整个学习进度压成一串 69 个字符的短码，复制粘贴即可在电脑和手机之间同步（无需账号、不依赖任何服务器）
- **中文报错翻译**：把 Python 的英文报错翻译成人话，还会专门提示「用了中文全角符号」这类新手高频问题
- **判题防硬编码**：输出正确但写法不对（比如直接 `print` 出答案）同样不给过，并说明该用什么写法
- **桌面软件级外观**：应用图标、PWA 清单、开机启动动画、窗口外壳与标题栏、可安装为独立应用
- **手机适配**：窄屏自动切换为竖向关卡列表

## 课程结构

| 章节 | 主题 | 关数 |
|---|---|---|
| 第 0 章 | Python 初识（预习卡片） | — |
| 第一章 | 咒语初现：print、运算、变量、类型、字符串 | 11 |
| 第二章 | 控制流：input、判断、循环、break/continue | 10 |
| 第三章 | 数据结构：列表、字典、函数、字符串方法、排序 | 19 |
| 第四章 | 进阶：异常、模块、类、文件、综合项目 | 18 |

练习分三档：**热身★**（照做即得）→ **巩固★★**（一步变形）→ **挑战★★★**（多步组合，常跨知识点）。

## 怎么用

**方式一：直接双击**

下载 `index.html`，双击用浏览器打开即可（首次运行需要联网下载 Python 运行环境，约十几秒）。

**方式二：本地服务器**（可选，体验更接近线上）

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

首次进入会看到启动动画，点「开始冒险」进入关卡地图。进度保存在浏览器本地（localStorage），换设备不会同步。

## 目录说明

```
.
├── index.html          # 成品：单文件应用（全部内容已内联，可直接打开 / 可直接部署）
├── src/                # 源码（便于阅读和修改）
│   ├── styles.css      #   全部样式
│   ├── courses.js      #   课程数据（66 关的题目、答案、判题规则）
│   └── app.js          #   应用逻辑（渲染、判题、游戏化、动画）
├── assets/             # 应用图标与吉祥物
└── docs/               # 教学大纲与设计文档（Word）
```

> `index.html` 是由 `src/` 里的三个文件**内联打包**生成的成品。改内容请改 `src/`，然后重新内联。

## 技术栈

- 纯 HTML / CSS / JavaScript，**无框架、无构建工具、无依赖**
- [Pyodide](https://pyodide.org/) 0.26.4（CDN 加载）提供浏览器内 Python 运行时
- 字体与图标全部内联为 data URI，离线可用

## 判题是怎么做的

1. **输出比对**：归一化换行与行尾空白、全角/半角标点统一后逐字比对
2. **写法约束**：用正则强制关键知识点（例如排序题必须出现 `sorted(`，类题必须 `class X`），防止「直接打印答案」蒙过去
3. **模拟输入**：需要 `input()` 的题目会注入预设输入，学生不必手动敲
4. **差异可视化**：判错时并排显示「你的输出 / 期望输出」，保留换行、用 `·` 标出看不见的空格

## 已知限制

- 首次运行需要联网加载 Pyodide（约十几秒）
- 学习进度存在本地浏览器，**不会自动同步**；换设备需要用「进度码」手动搬一次（点右上角 ⟳ 图标）
- 教师端统计需要后端，目前未实现
